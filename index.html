1.1 Proposiciones, conectivos y reglas de negocio

La base matemática detrás de cada Si … Entonces e if

Una proposición es un enunciado declarativo al que se le puede asignar sin ambigüedad un único valor de verdad: Verdadero (V) o Falso (F). Las preguntas, órdenes o exclamaciones no son proposiciones. Cuando combinamos proposiciones simples (p, q, r, s) mediante conectivos lógicos obtenemos proposiciones compuestas capaces de modelar reglas de negocio reales, como aprobar un crédito en la Papelería Sugamuxi: (p ∧ ¬q) ∨ r.

ConectivoSímboloPSeInt / PythonRegla fundamental de verdad
Negación¬pNO p / not pInvierte el valor: si p es V, ¬p es F.
Conjunciónp ∧ qp Y q / p and qSolo es V cuando ambas son V.
Disyunciónp ∨ qp O q / p or qSolo es F cuando ambas son F.
Condicionalp → q(¬p) O q / (not p) or qÚnicamente es F cuando antecedente es V y consecuente es F (V → F = F).
Bicondicionalp ↔ qp = q / p == qEs V cuando p y q tienen exactamente el mismo valor de verdad.
Clasificación de una fórmula
Tautología: todas las filas de la columna final son V.
Contradicción: todas las filas son F.
Contingencia: combina resultados V y F.
Leyes de De Morgan (útiles al programar)
¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q
Permite simplificar condiciones negadas complejas en un if.

2.1 Concepto de algoritmo, tipos de datos y diagramas de flujo

De «El procesador humano» a la representación gráfica formal

Un algoritmo es una secuencia finita, ordenada y precisa de instrucciones sin ambigüedades que transforma unas entradas en un resultado esperado. Un computador no adivina lo que quisiste decir: ejecuta exactamente cada instrucción paso a paso.

Simbología de diagramas de flujo (PSeInt)

Cuidado con el redondeo de decimales terminados en .5
PSeInt redondea 2.5 hacia 3 (redondeo aritmético alejándose de cero), mientras Python 3 usa round-half-to-even (round(2.5) == 2). Por eso los casos de prueba de los talleres evitan resultados exactos terminados en .5 al redondear. Recuerda además que en Python input() siempre devuelve texto (str) y debe convertirse con int(…) o float(…).

def leer_positivo(msg):
    """Lee un número mayor que cero."""
    v = float(input(msg))
    while v <= 0:
        v = float(input("Debe ser > 0: "))
    return v

def mostrar_total(valor, tasa):
    """Calcula y muestra el total con IVA."""
    print(f"Total: ${valor * (1 + tasa):,.0f}")

def menu():
    op = 0
    while op != 3:
        print("1. IVA 19%  2. IVA 5%  3. Salir")
        op = int(input("Opción: "))
        if op in (1, 2):

5.1 Índices 1 vs. 0, vectores paralelos, burbuja y matrices

                
La diferencia clave entre PSeInt perfil Flexible y las listas de Python

              

            

          


          

            

              
Vectores (1D) y vectores paralelos

              

                En PSeInt (perfil Flexible), Dimension precios[5] usa posiciones de 1 a 5.

                En Python, precios = [4500, …] usa índices de 0 a 4 (y -1 para el último).

                Al tener codigos, nombres, precios y stock, el mismo índice i une los cuatro datos de un producto: si ordenas uno, debes intercambiar los cuatro a la vez.
              

            

            

              
Matrices (2D)

              

                Una tabla de F filas y C columnas: Dimension ventas[3, 4] en PSeInt (ventas[f, c]) o lista de listas en Python (ventas[f][c]).

                Para sumar por fila, el ciclo externo recorre f y el interno c; para sumar por columna, se invierte el orden de los ciclos (externo c, interno f).

16 conceptos fundamentales de la Guía 03

              

            

          


          

            
Condicional (p → q)Clic para ver
Solo es Falso cuando el antecedente (p) es Verdadero y el consecuente (q) es Falso. En todos los demás casos es Verdadero.

            
TautologíaClic para ver
Proposición compuesta cuya columna final en la tabla de verdad es Verdadera (V) en el 100 % de sus filas.

            
Jerarquía (^, MOD, Y, O)Clic para ver
1. Paréntesis → 2. Potencia (^) → 3. * / MOD → 4. + - → 5. Relacionales → 6. NO → 7. Y → 8. O.

            
Modelo EPSClic para ver
Entrada (Leer datos) → Proceso (Cálculos y decisiones) → Salida (Mostrar resultados). Primer paso de todo algoritmo.

            
Prueba de escritorioClic para ver
Ejecución manual del algoritmo paso a paso registrando en una tabla el valor de cada variable y la salida.

            
Según vs. if / elifClic para ver
Según compara una variable con valores exactos; en Python (lineamiento Guía 03) se codifica con if / elif / else.

            
Mientras vs. RepetirClic para ver
Mientras evalúa al inicio (0 o más veces). Repetir evalúa al final (al menos 1 vez); en Python: while True + if: break.

            
Bandera (Flag)Clic para ver
Variable lógica (Verdadero/Falso) que recuerda si un evento ocurrió durante la ejecución de un ciclo.

            
Función vs. SubProcesoClic para ver
La función retorna un valor (return). El procedimiento o SubProceso ejecuta una acción sin retornar valor (None).

            
Valor vs. ReferenciaClic para ver
Por valor trabaja sobre una copia (el original no cambia). Por referencia actúa sobre la variable/objeto original.

            
Índice 1 vs. Índice 0Clic para ver
En PSeInt (perfil Flexible) los arreglos inician en la posición 1; en Python las listas inician en 0 y llegan hasta len(v)-1.

            
Vectores paralelosClic para ver
Arreglos independientes del mismo tamaño donde la posición i relaciona los campos de un mismo registro.

            
Método de la burbujaClic para ver
Algoritmo de ordenamiento que compara vecinos (j y j+1) e intercambia si están en desorden hasta dejar todo ordenado.

            
Modos r, w y aClic para ver
"r" lee (falla si no existe); "w" crea o sobrescribe desde cero; "a" agrega datos al final conservando lo previo.

            
csv.DictReaderClic para ver
Lee cada fila de un CSV como un diccionario usando los encabezados de la primera línea como claves.

            
try / exceptClic para ver
Captura excepciones como FileNotFoundError o ValueError evitando que el programa aborte ante datos o archivos faltantes.

10.2 Glosario técnico interactivo (28 términos)

                
Filtra por palabra clave o categoría temática

              

            

          


          

            
            
            
          


          

            
            
            
            
            
            
          


          

            
Lógica
Proposición
Enunciado declarativo del que se puede afirmar sin ambigüedad si es verdadero o falso, pero no ambas cosas.

            
Lógica
Tabla de verdad
Tabla que muestra el valor de verdad de una proposición compuesta para todas las combinaciones (2ⁿ) de sus proposiciones simples.

            
Lógica
Tautología / Contradicción / Contingencia
Fórmula siempre verdadera (tautología), siempre falsa (contradicción) o que combina V y F según los valores de entrada (contingencia).

            
Lógica
Jerarquía de operadores
Orden de precedencia al evaluar expresiones: paréntesis, potencia, * / MOD, + -, relacionales y lógicos (NO, Y, O).

            
Lógica
Operador MOD / %
Devuelve el residuo entero de una división (ej. 7 MOD 3 = 1, útil para verificar múltiplos o números pares).

            
Algoritmos
Algoritmo
Secuencia finita, ordenada y precisa de pasos que resuelve un problema a partir de datos de entrada.

            
Algoritmos
Modelo EPS
Descomposición de un problema en Entradas (datos recibidos), Proceso (transformaciones) y Salidas (resultados).

            
Algoritmos
Pseudocódigo
Descripción de un algoritmo en lenguaje cercano al natural con palabras clave estructuradas, independiente de un lenguaje concreto.

            
Algoritmos
Diagrama de flujo
Representación gráfica de un algoritmo mediante símbolos normalizados (óvalo, paralelogramo, rectángulo, rombo) unidos por flechas.

            
Algoritmos
Prueba de escritorio
Ejecución manual del algoritmo registrando en una tabla el valor de cada variable paso a paso para comprobar su lógica.

            
Algoritmos
Variable y Constante
Espacios con nombre en memoria; el valor de la variable cambia en ejecución mientras la constante permanece fija.

            
Control
Condicional anidada
Estructura Si colocada dentro de otra rama condicional (o encadenada con elif en Python) para evaluar múltiples tramos.

            
Control
Selección múltiple (Según)
Evalúa una variable frente a casos discretos y ejecuta el bloque coincidente o De Otro Modo.

            
Control
Contador
Variable que aumenta o disminuye en una cantidad fija (generalmente 1) cada vez que ocurre un evento dentro de un ciclo.

            
Control
Acumulador
Variable que suma (inicia en 0) o multiplica (inicia en 1) valores variables a lo largo de las iteraciones de un ciclo.

            
Control
Bandera y Centinela
Bandera: variable lógica que indica si algo ocurrió. Centinela: valor especial (ej. 0) que le indica al ciclo cuándo detenerse.

            
Funciones
Función
Subprograma que recibe parámetros, realiza una tarea y retorna un resultado al punto donde fue llamado.

            
Funciones
Procedimiento (SubProceso)
Subprograma que ejecuta acciones (como imprimir o modificar una lista) sin retornar valor alguno.

            
Funciones
Parámetro por valor / por referencia
Por valor recibe una copia (el original no cambia); por referencia recibe la variable/objeto original (los cambios persisten afuera).

            
Funciones
Docstring
Cadena entre triples comillas al inicio de una función en Python que describe su objetivo, parámetros y valor de retorno.

            
Arreglos
Arreglo (Vector / Matriz)
Estructura en memoria que almacena múltiples valores bajo un nombre accedidos por índice; vector tiene 1 dimensión y matriz 2.

            
Arreglos
Vectores paralelos
Conjunto de vectores del mismo tamaño donde la misma posición i agrupa los atributos de un mismo registro.

            
Arreglos
Ordenamiento por burbuja
Método que recorre un arreglo comparando pares vecinos e intercambiándolos si están en desorden hasta dejar todo ordenado.

            
Archivos
CSV (Comma-Separated Values)
Archivo de texto plano donde cada línea representa un registro y sus columnas se separan mediante comas.

            
Archivos
Sentencia with open()
Administrador de contexto en Python que garantiza el cierre automático del archivo al finalizar o si ocurre una excepción.

            
Archivos
CRUD
Acrónimo de las cuatro operaciones básicas de persistencia: Crear (Registrar), Leer (Listar/Buscar), Actualizar (Modificar) y Eliminar.

            
Archivos
FileNotFoundError
Excepción lanzada por Python al intentar abrir en modo lectura ("r") un archivo que aún no existe en disco.

            
Archivos
ValueError
Excepción lanzada cuando una función como int() o float() recibe un texto que no corresponde a un número válido.
